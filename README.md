# 🚀 Proj — Mini Projects Collection

A curated collection of small, focused mini-projects (mostly **C++**) built to practice fundamentals and serve as a portfolio.  
Each folder is a standalone project with a clear purpose and its own implementation. ✨

---

## 📦 Projects

- 📝 **`mini_text_editor`** — Terminal-based mini text editor (C++)
- ✅ **`todo_list`** — Simple TODO list app (C++)
- 🗂️ **`file_organizer`** — Utility to sort/organize files (C++)
- 🧠 **`algo`** — Algorithms / sorting (sometimes visualization)
- ⚽ **`collision_simulation`** — Simulation / collisions (sometimes visualization)
- 🔤 **`asciiConverter`** — ASCII / converter tool

> Goal: keep projects **small and focused** instead of building one huge app. 🎯

---

## ⚙️ Quick Start (Recommended)

### 1) Clone the repo 📥
```bash
git clone https://github.com/Raiza04/Proj.git
cd Proj
```

### 2) Pick a project 📂

```bash
cd mini_text_editor
```

### 3) Build & run using build.sh 🛠️✅

I mainly use build.sh — it handles compilation automatically.
In most cases you don’t need to run Make/CMake manually.

```
chmod +x build.sh
./build.sh
```

If a project has a different setup, it will be mentioned inside the folder (or you can spot files like CMakeLists.txt). 🔎
